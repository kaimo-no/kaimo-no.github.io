# kaimo-no.github.io

Marketing landing for [kaimo](https://github.com/kaimo-no/kaimo-go) — a UK agent-commerce platform that gives AI agents a checkout.

Live at: <https://kaimo-no.github.io/>

Product source: <https://github.com/kaimo-no/kaimo-go>

## Editing

This is a single static `index.html` with inline CSS — no build step. Edit, push to `main`, GitHub Pages redeploys in under a minute.

The waitlist form posts to [Formspree](https://formspree.io/); the form ID is the `formspree.io/f/{id}` path on both `<form action>` attributes in `index.html`.
